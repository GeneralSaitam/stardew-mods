THIS MOD REQUIRES SMAPI AND CONTENT PATCHER
This mod adds a sheltie dog breed that you can choose at the start of the game, or adopt later. It doesn't replace the original dog breeds.

Instructions: 

- Download and install latest version of SMAPI﻿
- Download latest version of Content Patcher﻿ and extract in ''Stardew Valley/Mods'' folder
- Download ''Izabelleanne's Sheltie Collie dog - Add dogs'' mod and extract in ''Stardew Valley/Mods'' folder
- Run the game with SMAPI et voilà!
