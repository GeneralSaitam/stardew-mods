Introduction
------------
Billboard Beautifier adds seasonal tinting and festive flair to your Stardew Valley calendar.  The calendar will be updated for each
season with striking pixel art garnishes, giving the calendar a fun refresh.  From plain to picturesque — one month at a time.
This mod shuold not conflict with any other currently available at the time of this writing as no one else has done this before that
an AI search turned up.

This no longer uses static images, instead applying all flair dynamically, thus it preserves localization.  It still experiences so overlap
because the flair gets added before the game applies the events and birthday indicators.  I did the best I could with the limitations imposed.
I hope you can overlook those small issues.

I already have some exciting enhancements bouncing around in my noggin, so expect updates in the future...

The calendar layout will stay the same for the session and the season.   For example, you load the game on Summer 26, then the Summer calendar 
layout will stay the same image until you flip to Fall.  Fall will stay the same until Winter.  If you exit the game and reload a save later,
then a new calendar layout is generated for the session.  There are several neat flari to enjoy.  I hope you enjoy the variety.

Compatibility Notes
------------------
This mod overrides the calendar texture used by certain recolor mods (such as DaisyNiko’s Earthy Recolour) in order to apply seasonal tinting
and dynamic flair. This is intentional and necessary to preserve visual clarity and functionality. Mods that recolor only the small wall calendar
(e.g., Calendar Recolors by Lunightmare) are unaffected.

Some mods that add items directly onto the calendar may overlap slightly with Billboard Beautifier’s flair elements. This is expected, as Billboard
Beautifier intentionally overlays parts of the calendar while avoiding important gameplay indicators whenever possible.

Billboard Beautifier is not compatible with Calendar Crops.  Both mods patch the same calendar regions, and running them together causes 
unavoidable visual conflicts. Since Calendar Crops predates this mod, Billboard Beautifier will automatically disable the calendar changes when Calendar
Crops is detected to preserve your game’s appearance.  The Help Wanted enhancement will still work!  If you remove Calendar Crops, Billboard Beautifier
will function normally. Thanks for understanding!
